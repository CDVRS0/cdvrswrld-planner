# Daily focus and fresh start

The home page shows up to three explicitly chosen priorities, the selected day's real actions and scheduled commitments, plus a separate backlog. Default OS checklist prompts are still in the guided flow and no longer inflate daily task metrics or carry-forward lists. Add to today explicitly promotes a prompt into a real action. Existing custom actions are recognised without editing the original saved records.

Home-page Delete and Start fresh open an itemised review. Only selected unfinished actions are removed after approval. Local and carried actions are soft deleted inside the existing weekly cloud snapshot; cloud tasks use the existing cancelled status. Deleted actions can be restored. Completed work, OS prompts, notes, schedules, calendar events and source-day tasks referenced by a handoff are retained. Task writes compare owner, timestamp and status and refuse stale changes. Fresh start never includes backlog tasks automatically.

Backlog contains earlier real custom actions and earlier/unscheduled cloud tasks. Adding a prior local action to the selected day creates a carry-forward reference and retains the source day.

Validation includes template classification, explicit promotion, duplicate titles, selected-day/backlog separation, three-priority limit, reversible removal, carried cloud references, preserved notes/calendar and stale or denied writes. Browser checks use only a disposable fixture account.
