# Phase 2 — Adaptive AI Planning

The current release is the tested Planner foundation: cloud sync, calendar reads,
section chat, reflection, reviewed handoff/carry-forward and approval-based daily
recommendations/time blocks. It does not implement the full adaptive milestone.

The owner's clarified Phase 2 scope is:

1. Intelligent rescheduling: recommend new times for missed work using remaining
   commitments, deadlines and priorities. Start here: “I didn’t finish my music
   today. Rearrange tomorrow.” Show before/after changes, allow edits and require
   approval before saving. Never silently move external calendar events.
2. Routine learning: improve recommendations from actual completion history,
   preferred working hours, energy and recurring commitments. Distinguish weak
   evidence from established patterns and keep any learning transparent.
3. Dynamic daily scheduling: propose changes when available time or commitments
   change. The user reviews and approves before saving.
4. Weekly reviews: examine completed/postponed work, project progress and whether
   schedules were realistic, then recommend changes for next week.
5. Cross-system intelligence: bring Nature, GYM, basketball, music and business
   into planning using explicitly authorised records and recovery constraints.

Do not claim these adaptive capabilities are shipped with the foundation release.
Examples/illustrations must be labelled as demonstrations rather than live data.
Maintain approval gates, existing data, efficient model routing and fast response.
